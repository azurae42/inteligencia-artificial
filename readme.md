Este es el repositorio de trabajo para la asignatura 'Inteligencia Artificial' del plan de estudios de Licenciatura en Ingeniería en Computación de la Facultad de Matemáticas de la UADY.

La carpeta `workbench/` contiene los directorios con tareas y ejercicios en proceso, es decir, estara cambiando constantemente.

Los resultados/entregables de cada ejercicio se encuentra en su carpeta correspondiente en `Entregas/`. Cada directorio de ejercicio también incluye los archivos de código fuente o libretas Jupyter necesarios para reproducir los resultados.
